# 第二阶段测试

在第一阶段应用上测试新增模块，不替换原用例或Allure证据。所有业务写入、故障注入、升级及恢复仅进入本轮随机专用库，结束后清理该库。服务必须是MongoDB 7+副本集。运行前安装原测试依赖，参见[总测试说明](../../README.md)。

```powershell
# 在仓库根目录运行；使用根目录的虚拟环境
& './code/.venv/Scripts/python.exe' test/工具/run_phase2_tests.py --collect-only
& './code/.venv/Scripts/python.exe' test/工具/run_phase2_tests.py --mongo-uri 'mongodb://127.0.0.1:27018/?replicaSet=survey-rs'
```

`--batch 1/2/3/transactions/migration`可单独执行。输出到全新`test/执行记录/完整系统回归/本地运行/phase2-*/`，含JUnit、日志、运行摘要，不覆盖历史记录。脚本失败会返回非零退出码。原批次执行摘要见[历史测试执行记录](../../执行记录/第二阶段/README.md)。2026-10-29 七项加强后的实际结果见[现有用例加强记录](../../工具/整理记录/第二阶段来源说明/现有用例加强记录.md)：三个业务批次 8/4/15 项通过，全量 43 项通过。
